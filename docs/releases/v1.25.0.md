# Chatbox Venice 1.25.0

## Features

- **Simpler media UI:** choose models by name, model-specific voices, language, speed, compatible formats, an explicit voice preview, video duration and readable cost estimates. Technical IDs and JSON stay under Advanced options. Profiles use normal selectors.
- **Optional Venice Studio:** speech, file transcription, video, music and sound effects. Explicit catalog loading, manual model IDs and vendor JSON are supported. Available models, formats and options depend on the API catalog.
- **On-device history:** playback, export, local deletion and separate remote cleanup. Video/music queue IDs survive interruptions so retrieval can resume without creating another paid job. Cleanup is requested after local saving; failures remain visible and can be retried.
- **Work Mode media tools:** separately enabled and limited to records from the current chat. Generation asks by default; deletion always asks. Existing filesystem and MCP permissions remain in place.
- **Venice profiles:** reusable presets and model/chat overrides for search, engine, citations and image moderation. Extra model request JSON has final precedence.
- **Provider switch:** disable new Venice requests while retaining saved content. Audio/video/music modules remain opt-in.
- **Actions tests:** mocked API responses, real React interactions and Chromium desktop/phone screenshots. No real API key or paid inference is used.
- **Personal release-mode APK:** CI signs the release APK using a key pinned from 1.25.0, or dedicated secrets. Certificate verification and optional encrypted key backup protect update continuity. The older 1.24.2 APK has a different certificate.

## Installation and limitations

Download the Windows x64 setup or Android APK from this release. Windows setup has no commercial signature. Android updates require the same signing key: [personal distribution and backup](https://github.com/n3me5is-git/chatbox-venice/blob/main/docs/personal-distribution.md). Building/signing the APK does not require a Google Play account; device installation follows the applicable Android process.

Requests go directly to Venice. Audio, video and music are not E2EE. E2EE/TEE attestation, voice cloning and voice conversion are not implemented. Paid generation is never automatically retried after an error. Stopping the wait or closing the app may not cancel a job or its server-side cost. Limits: transcription uploads 25 MB, generated media downloads 128 MiB.

Studio history is separate from portable chat/image backups. Export important media before resetting or migrating. User-exported files and backups remain in the locations you selected.
