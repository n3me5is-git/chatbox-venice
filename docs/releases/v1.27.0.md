# Chatbox Venice 1.27.0

## Chat-scoped generation approval

- Choose **Ask every time**, **Remember similar generations after approval**, or **Automatically approve generations** from **Venice approvals** beside the chat balance, or in a generation approval dialog.
- Policies apply to native Venice image, speech, video and music tools in the current chat. Other chats start with their own policy. Permissions stay in memory and disappear when the app closes; they are not exported in backups.
- Similar generations use the same tool, model and canonical generation parameters. The prompt may change. A different model, batch size or parameter set needs another approval. Image calls can reuse the per-call ratio, moderation, format, seed and extra JSON chosen in the first approval.
- Automatic mode is explicit and can create paid content without additional prompts. Unknown/ambiguous image models and required reference uploads still open the picker. Destructive local/remote deletion still asks.
- **Reset approvals for this chat** immediately restores asking and clears remembered grants/defaults. Credential, endpoint or relevant provider/model setting changes invalidate permissions. Pending automatic image calls recheck revocation before starting.
- Provider-wide legacy confirmation bypasses are superseded by the current chat policy. Existing filesystem command permissions and external MCP integrations retain their settings.

## English source and localization

- GitHub release notes and primary documentation use English. Published 1.25/1.26 notes are synchronized from the English files without replacing their packages or tags.
- Fork UI uses the app's existing i18n resources and reacts to language changes without a restart. English is the source and fallback; Italian translations are included, and core approval controls are translated across all 15 supported desktop locales. Existing translations remain intact. New messages without a locale-specific translation fall back to English.
- Voice labels, interpolation placeholders, credits, playback speed and cost formatting follow the active locale. API model/voice IDs and vendor parameters remain unchanged by translation.

## Verification and downloads

Actions runs focused functional tests, actual React component interactions, TypeScript, signing checks and Chromium desktop/phone simulation before compiling the Windows x64 setup and Android APK. Approval tests cover isolation, repetition, model/settings changes, cancellation, revocation and a fresh app lifetime. Localization checks cover English, Italian, French and resource/placeholder consistency across every supported locale.

Generation responses in CI are simulated; no real Venice key or paid inference is used. Live provider access, installation, codec support, microphone permissions and export on physical devices remain to be verified with your own key/device.

This release includes the features and fixes from [1.26.0](https://github.com/n3me5is-git/chatbox-venice/blob/main/docs/releases/v1.26.0.md): profiles/thinking, global search, internal MCP, images in chat/Studio, batch/remix/edit, credits, model-specific music/video inputs, microphone transcription, embeddings/RAG and mobile selector fixes.

Android retains the signing identity pinned from 1.25.0. Windows setup is unsigned. Generated media downloads remain limited to 128 MiB and assembled in RAM/base64; direct disk streaming and byte-range resume are not implemented. Studio media history remains separate from portable chat backups. E2EE/TEE attestation and voice cloning/conversion are not implemented.
