# 1.42.0 — Protected knowledge collections on Android

- Add reusable global knowledge collections on Android and desktop, with encrypted source files, filenames, metadata and vector shards.
- Protect each collection with app unlock or a dedicated PIN/passphrase and device biometrics. Protected chat-tool reads request owner authentication before exposing documents or contacting embedding providers.
- Share bounded local document extraction and recursive chunking with session RAG. Add EPUB, OpenDocument, RTF and HTML alongside PDF, DOC/DOCX, XLSX, PPTX, Markdown, text and source code.
- Keep direct photo/audio embeddings independent from OCR/transcription. Prefer configured Venice models explicitly marked private. Venice currently exposes text-only embeddings, including its Gemini model; native media embeddings remain available through direct Gemini Embedding 2.
- Offer optional reranking, local semantic-search previews, per-document deletion and index cleanup. Preserve the original desktop KB manager and legacy collections, with an explicit local copy into encrypted collections.
- Add English and Italian interface text, with English fallback for other app languages.

Rebuild existing session RAG indexes once to use the updated chunker. Legacy desktop copies remain unencrypted until separately deleted; copying indexed text is not an exact original-document/vector migration. Embedding, OCR and reranking providers receive the enabled inputs, independently of chat E2EE. Device biometrics require enrollment on the device.

See [protected collections and privacy boundaries](../protected-knowledge-collections.md).
