# Chatbox Venice 1.36.0

- Add `venice_media` actions `wait` and `show`. Waiting observes the existing background job for up to 60 seconds and reports ready, failed, paused or still processing. It never starts another generation or silently resumes an interrupted job.
- Attach saved Venice speech, music, sound effects and video to the conversation as artifact cards. A queued result becomes playable when the background job finishes, without reloading the chat. The agent can recall a saved result using its existing identifier.
- Open playback in a modal using the same local media viewer as the session explorer. No autoplay or provider call is required to open a saved file. Load selected content only, release decrypted byte buffers and revoke the playback URL when the viewer closes.
- Keep session ownership, protected-preview authentication, deletion and privacy-lock boundaries. No model-supplied URL or storage key is used to load an artifact. Add English/Italian interface text and regression checks for these boundaries.

Playback keeps the existing explorer preview limits. Large files can still be exported from the explorer or Studio. Closing a wait stops that wait; it does not guarantee cancellation of server-side generation or its cost.
