# Chatbox Venice 1.44.0

- Add optional hybrid semantic/BM25 retrieval, source-grounded entities, relations, summaries and LLM reranking to encrypted knowledge collections.
- Link read-only device folders with hash-based incremental updates, retained encrypted copies and optional automatic indexing.
- Review answer support before publication, inspect clickable source assessments and optionally correct conflicting claims with a separately approved model.
- Search several collections together and explore a bounded, source-linked knowledge graph.
- Expose selected collections and source-review tools through separately permissioned desktop MCP endpoints.
- Activate global knowledge tools in Android Work chats, including resumed tool calls.
- Reduce vector archive size, retain older index compatibility and paginate large document lists.
- Preserve required reasoning and signed response replay through source-review approval pauses.
