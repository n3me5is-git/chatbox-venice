# Chatbox Venice 1.24.1

First release of the Venice-focused fork, based on Chatbox Community Edition 1.24.0.

- Extra request JSON per custom model, including nested vendor options and image moderation. Local aliases can target the same remote model with different settings.
- Venice provider with API key authentication and live discovery of chat, image generation and image editing models.
- Native chat search plus Brave, Google and Exa retrieval through Venice, URL reading, citations and X search on compatible models.
- Venice image controls for safe mode, image web search, negative prompts, format, size, resolution, quality, seed, steps, CFG, style, watermark and optional prompt enhancement.
- Local generation history and deletion of generated images; direct Venice API requests.
- Automated Windows x64 setup and Android APK builds on GitHub Actions.
- Fork-specific update feed, downloads and documentation.

Windows setup is unsigned. The Android APK is a development-signed build for sideloading; it is not a Play Store release. Android device testing and live Venice API calls require user validation. Automated provider tests use mocks and never use a real API key.

Audio, video and music interfaces are planned separately. Existing local Work Mode and MCP support are retained; see the documentation for the optional Venice MCP server.
