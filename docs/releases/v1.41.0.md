# 1.41.0 — Session RAG and linked workspaces

Session files can now be indexed using an explicitly selected embedding provider. An encrypted, segmented local vector index lives under `.chatbox/rag/` in the session tree. Semantic search and passage retrieval return file links and line/page references. Manual indexing and foreground automatic updates reuse unchanged file hashes.

- Local extraction for PDF, Markdown, legacy Word DOC, DOCX and text/source files. Optional OCR uses a selected vision model. Direct image/audio embeddings are separately opt-in for supported Gemini Embedding 2 models.
- Desktop and Android can link a device folder as their main workspace. Dedicated agents receive separate subfolders with independent app capabilities. Disconnecting a folder or deleting a chat preserves the external files.
- RAG and source previews use shared tools on desktop and Android. Device-local consent is required before a transferred chat can call an embedding/OCR provider.
- Child-agent subscription image approvals are routed through the root shared conversation; generated artifacts remain assigned to the child session.
- English and Italian UI, with English fallback for other locales.

See [architecture, privacy boundaries and limits](../session-rag-and-linked-workspaces.md). Linked folders remain ordinary device files; app locking does not encrypt those external files.
