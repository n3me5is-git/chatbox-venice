# Chatbox Venice 1.40.0

Shared sessions open as full remote chats and appear in a **Remote chats** sidebar group. Read and interact with the host's conversation, see verified participant names, follow live replies/tool activity, answer permitted approvals and open shared files on demand. The host keeps its model, credentials, MCP configuration and security policy. Collaborators with AI interaction permission can change supported thinking levels and the independent Chatbox/model-native search controls. Close or manage a connection from its sidebar menu. Update both devices before sharing.

Type **@** inside the prompt to find dedicated agents by technical name, files in the current session, accessible conversations and enabled MCP tools. Keyboard navigation, touch selection and cancellation work inside the composer; the separate @ button has been removed. Conversation references expose a bounded text reader in Work mode, limited to conversations explicitly tagged in the current owner request. Other protected projects and other host conversations stay unavailable to remote participants. Tool mentions do not grant permissions.

Work chats using **OpenAI Sub Unofficial** gain a `chatgpt_image` tool, using the configured subscription image endpoint. It takes priority for image requests with that provider, asks for confirmation, supports session image references and saves durable session/library outputs. The image tool can be disabled in provider settings. Replayed calls reuse the existing job; a failed image cannot trigger repeated paid-generation dialogs in the same user turn. No automatic fallback to another provider or API billing.

Native ChatGPT search is registered as a distinct SDK provider tool. Stateless history repair reconstructs legacy native `ws_…` search items instead of replaying orphan function outputs, including after native search is disabled. Ordinary client search and MCP call/output pairs are preserved.

Venice provider settings add **Limit Venice tools to Venice models**. When enabled, other-provider chats cannot expose those tools. Without the limit, each other-provider Work chat starts with Venice tools disabled and can opt in from its MCP controls. Venice chats retain their existing default. ChatGPT subscription image tools remain limited to subscription chats and the general image generator.

The native image model picker has explicit mobile viewport bounds, independent touch scrolling, visible provider groups and search by model name, ID or provider. Venice Studio keeps its Venice-only catalog. New controls include English and Italian translations.

CI exercises host permissions and revocation, real browser-to-browser encrypted WebRTC, streaming remote replies, on-demand file previews, shared HITL, prompt mention interactions, subscription image routing/idempotency, multi-turn native search replay and the last model in a long multi-provider mobile picker. Account entitlement, image quota and physical-device behavior still depend on the connected account and device.
