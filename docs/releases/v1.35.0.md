# Chatbox Venice 1.35.0

## Encrypted collaborative chats

Share a saved chat with a pairing code or QR from the people icon. Join from **Collaborative chats** in the sidebar. The owner admits participant IDs and grants read/write, AI/tool interaction and cloning permissions independently. Multiple sessions remain active while the app is open; the green people icon indicates an active share.

Each share has three agent-question/approval policies: **owner only**, **everyone / first valid answer**, or **the initiating participant only**. This covers questions with choices and custom text, Venice generation decisions and explicit Retry/Skip after failures. The host validates responses and closes answered requests everywhere. Existing device security approvals remain owner-side.

WebRTC DTLS is supplemented by per-peer AES-GCM encryption with an invitation-pinned owner key. Public relays provide signaling. Chats/files travel encrypted between devices; provider keys are not distributed. AI and MCP calls still use the owner's existing provider/privacy settings. Sharing is revoked on lock, chat deletion or app exit.

Guests can preview supported files and, if permitted, clone the conversation and all accessible resources into encrypted local storage. File transfer uses acknowledged chunks. Individually protected creations and other-project assets are excluded. Imports keep scripts inactive; intermediate files stay out of the library. Archived threads/alternative replies are preserved as a linear transcript rather than recreating branch navigation. Read permissions cannot prevent manual copying. See the [collaboration guide](https://github.com/n3me5is-git/chatbox-venice/blob/main/docs/collaboration.md) for limits and network requirements.

## Venice catalog, costs and generation errors

- Correct stale saved types/privacy metadata that could hide enabled image models such as Krea 2 Turbo. Live facts take precedence while preserving user labels and extra parameters.
- Review all 405 current catalog entries. Keep queued ElevenLabs/Seed speech in Voice, voice changer in Voice conversion, and sound effects separate from music. Stable Audio 2.5 is available for both music and sound design. Explicit video input flags override name guesses.
- Show available prices and billing units in model menus, configuration lists, Image Creator and Studio. Use ranges for resolution/quality tiers; request an estimate when the catalog has no fixed rate. Cost is not a quality score.
- Display failure reasons directly in Image Creator/Studio and failed history entries. Preserve useful structured HTTP validation messages without persisting arbitrary response bodies or unrelated request data. No automatic paid retries.

English and Italian strings are included with English fallback. See the [catalog audit](https://github.com/n3me5is-git/chatbox-venice/blob/main/docs/venice-catalog-audit-2026-11-08.md).

## Validation and distribution

Actions run TypeScript, existing regression/UI suites, all-catalog tests, encryption/replay/permission tests and real three-browser WebRTC flows with local signaling. Browser checks include phone layouts, model selection, costs and failure reasons, without inference charges. Public Internet NAT combinations and physical phones still require network/device testing.

Windows x64 setup and the Android APK are built by Actions. Android retains the existing private repository signing identity; Windows remains unsigned for personal use. This release includes the 1.34.1 microphone, search and file-explorer fixes.
