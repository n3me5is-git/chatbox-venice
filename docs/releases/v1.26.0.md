# Chatbox Venice 1.26.0

## Fixes and features

- **Profiles and thinking:** fix dropdown resets when editing models; save/reopen is covered by a real modal regression test. Venice exposes the thinking levels declared by each model, including max/xhigh where available.
- **Global Venice web search:** choose Venice in Web Search settings, with Brave, Google or Exa using the provider key. Native chat search retains its separate configuration.
- **Images from chat:** a native tool opens a model picker and human approval for prompt, references, batch count, format, moderation and per-call JSON. Exact catalog names/IDs are preselected; missing, unavailable or ambiguous names require human choice. This version always asks before paid image generation and never replays an already-started tool call automatically.
- **Internal Venice MCP:** an in-memory client/server transport inside the app, with no external process or open port. Its switch is visible in Settings → MCP and Venice provider settings. Use a tool-capable Venice model in Work Mode. Voice/video/music modules are enabled separately.
- **Image catalog and mobile layout:** retain editing capabilities for models not manually added; scrollable selectors and mobile toolbar. Batch sizes 1–4, prompt reuse, remix and editing with compatible models from the same provider.
- **Studio images:** share the Venice image generator/history alongside speech, transcription, video and music.
- **Credits:** show USD, DIEM and other balances returned by the API in provider settings, Studio and Venice chats; manual refresh is available.
- **Music and sounds:** remove unsupported generic parameters that caused HTTP 400. Duration, lyrics, instrumental mode, loop, voice, language and speed follow the selected model; reset incompatible choices when it changes. Default payloads are checked against a snapshot of all 19 public music models.
- **Model details:** declared options, privacy, moderation and metadata, plus Venice model/API documentation links. Embedded browser and external/Chrome opening on supported Windows/Android hosts.
- **Video inputs:** start/end frames, multiple references, video editing and audio/video references for compatible workflows. Hide unsupported controls and validate required inputs.
- **Microphone transcription:** record locally or choose a file. Audio is uploaded only after selecting Transcribe; recording is limited to 3 minutes/25 MB.
- **Venice embeddings:** discover and select embedding models for knowledge bases/RAG. The /embeddings request is covered by a real SDK serialization test; indexed text goes to Venice while documents and the vector index stay local.
- **Cleaner selectors:** Appearance setting to hide Chatbox AI; provider-declared privacy/moderation indicators. Advertised E2EE capability does not mean this app implements E2EE.

## Downloads and verification

Download the Windows x64 setup and Android APK from this release. Android retains the identity pinned from 1.25.0. Windows setup is not commercially signed. See [personal installation and signing](https://github.com/n3me5is-git/chatbox-venice/blob/main/docs/personal-distribution.md).

Actions passed 321 focused functional tests, 109 UI tests, TypeScript, signing tests and Chromium desktop/mobile simulation before building the packages. Generation responses are mocked: no Venice key or paid inference is used. Live model access and installation, playback, codecs and export on physical devices still require validation.

## Known limitations

Catalogs and model limits can change. Guided video inputs use declared metadata and identifiable workflows; advanced JSON remains available. Multiple references are limited to 4 files per type, images to 10 MB, videos to 50 MB and audio references to 15 MB each; additional model duration/combination constraints still apply.

Generated media downloads remain limited to 128 MiB and are assembled in RAM/base64. This release does not add direct-to-disk streaming or byte-range resume. Remote cleanup is requested after local saving; a positive response is Venice's confirmation. Pausing or closing the app may not cancel server work or its cost. Studio media history is separate from portable chat backups: export important files.

E2EE/TEE attestation, voice cloning and voice conversion are not implemented. Some sites block embedded viewing; use Open in browser/Chrome. Not every API ID has a public model page; API documentation and catalog metadata remain available.
