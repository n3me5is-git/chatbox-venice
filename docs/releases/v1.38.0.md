# Chatbox Venice 1.38.0

- Send a complete chat, child-agent tree, session directories, files and generated media to another device through a direct encrypted peer connection. Open **Send to another device** in the chat menu; receive through the sharing panel's **Receive / transfer** tab using live QR scanning, an uploaded QR image or a pairing code. The sender approves the receiving participant before disclosing the manifest.
- Import a named new copy or explicitly replace a related local chat. SHA-256 and exact lengths reuse unchanged local files. Replacement publishes a complete new tree and archives the previous root only after success. A durable journal recovers interrupted imports; unpublished and abandoned snapshots are cleaned up.
- Rebuild local image history and audio/video artifact links without transferring provider credentials, device keys or remote paid-generation queues. Protected content requires explicit inclusion and a protected receiving project. Files are encrypted with the receiver's keys. Imported automatic execution, local filesystem grants and multi-agent permissions start disabled.
- Show ChatGPT subscription allowance remaining for the windows actually reported by the account, including five-hour and weekly limits. Tap the indicator in chat, image creation or provider settings for each reset date/time. Missing windows are omitted; missing balances never become an invented 0% or 100%. Account changes, disconnect and privacy lock invalidate stale results.
- Direct transfers participate in existing sharing background controls and **Close all active shares**. Manual locking stops transfer connections. Superseded pull-request checks are cancelled automatically.
- English UI and documentation with Italian translations and English fallback for other app languages.

Collaboration retains the pairing, TURN, camera scanning and three HITL policies from previous releases. Validation exercises actual two-peer WebRTC, admission-before-disclosure, acknowledged bounded chunks, SHA-256 verification, source changes and locking, plus real SQLite conversation imports and encrypted asset storage. Physical two-phone Android confirmation and real-account ChatGPT login/image availability remain separate device/account checks.

ElevenLabs Music reference audio remains a documented upstream/API discrepancy: Venice model pages advertise the capability, while the public audio queue, official CLI and official MCP music tool expose no reference-input field. This release does not add a nonfunctional attachment control or send guessed parameters.
