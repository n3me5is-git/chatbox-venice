# Chatbox Venice 1.37.0

## Work agents

- Delegate to on-demand workers using the current model and shared workspace, or dedicated profiles with their own model, prompt, selected tools and isolated sandbox.
- Configure the permitted profiles, nested profiles and parallel worker limit per Work chat. Maximum nesting is three child levels. Inspect execution state, conversations and sandbox files from the agent panel.
- Dedicated profiles can use a guardian that reviews tasks, messages, results and exact file bytes before crossing their boundary. A refusal blocks the operation and reports a reason to the caller. Review fails closed on invalid or uncertain decisions.
- Stored configuration, run metadata and files use the existing device storage/protection mechanisms. Interrupted work is not automatically replayed after restart.

## Desktop MCP multi-agent group

- New independent, default-off permission: **Run and manage this Work chat’s agents**.
- Exposes `agent_catalog`, `agent_tree`, `agent_spawn`, `agent_status`, `agent_message`, `agent_wait`, `agent_result`, `agent_files`, `agent_file` and `agent_stop`.
- The full nested tree is visible as metadata. Direct workers created by the current sharing grant can be controlled; guardian-reviewed summaries and file listings do not expose raw child transcripts or arbitrary sandbox access.
- Worker and nested-worker tools retain the intersection of chat policy, agent configuration and MCP sharing permissions, including read-only file access. File transfers require read/write grants and review the immutable transferred bytes.
- Guardian refusals return an MCP tool error with a structured reason. Stopping sharing cancels its workers and descendants, even if cancellation metadata cannot be saved. App locking and token revocation remain effective.
- This opt-in permission authorizes worker and guardian model charges. It does not enable disabled agents, bypass guardians or allow external clients to edit agent security policy.

## Other additions

- Separate community ChatGPT subscription connection with mobile device login and device-local encrypted credentials. Includes unofficial text/image transport; availability depends on the account and upstream service.
- Optional background collaboration control with a visible Android foreground notification, plus **Close all active shares**. Manual locking still stops sharing. The operating system may still suspend or stop the app.
- English labels and Italian translations for the added features, with English fallback for other languages.

The existing model picker, collaboration pairing, generation history protection, adjustable background-lock delay and chat media players remain included. Direct one-shot device session transfer is separate work and is not included in this release.

See [desktop MCP usage](../local-mcp-server.md) and the [guarded agent architecture](../guarded-multi-agent-architecture.md). Tests simulate model calls and use a real local MCP SDK transport; they do not send company data or incur provider generation charges.
