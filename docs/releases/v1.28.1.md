# Chatbox Venice 1.28.1

Fixes unlocking a protected creation from Image Creator history: it now requests that creation's dedicated project PIN, or app unlock when appropriate. Switching protected areas clears the previous PIN input.

Painted-area editing now keeps brush drags inside the image canvas on mobile. The browser simulation verifies a real touch stroke as well as the existing mask pixel, model-selection and approval checks.

Includes the encrypted media library, app/project protection, secure Venice text options, voice features and editing tools introduced in [1.28.0](v1.28.0.md). See [local security and backup boundaries](../local-security.md).

Tests use simulated provider/device responses; physical biometric unlock and paid inference still require target-device verification. Android retains the same signing certificate. Windows installers remain unsigned.
