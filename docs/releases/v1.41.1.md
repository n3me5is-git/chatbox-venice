# 1.41.1 — RAG privacy boundaries

Includes the [session RAG and linked workspaces in 1.41.0](v1.41.0.md).

- Private or other-project sources cannot enter a less protected session index, even when their keys are currently unlocked. Search, retrieval, direct index preview and workspace export recheck source scope changes.
- Derived index caches are omitted from collaborative sharing and direct device transfers. The receiving device can rebuild its index after approving its providers.
- General file, isolated execution and agent file-transfer tools cannot read or copy raw index artifacts. Semantic retrieval remains available with current source checks and citations.

Clear or rebuild an index to remove cached passages after changing source protection. Source files and existing chat messages are preserved. See [architecture and privacy boundaries](../session-rag-and-linked-workspaces.md).
