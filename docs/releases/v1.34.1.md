# Chatbox Venice 1.34.1

## Search settings

**Settings → Web Search → Venice → Expose separate search engines** now independently exposes `web_search_brave`, `web_search_google` and `web_search_exa`. With the switch off, the existing `web_search` tool uses the selected default engine. Other search providers keep their existing behavior.

These tools call Venice's `/augment/search` directly, without a text model, with separate per-engine caches and no automatic paid retries. Their pause state follows the global Chatbox search switch. Venice model/profile search remains separately configured and uses `venice_web_search_*` names. The desktop MCP server follows the global setting and retains its explicit search permission.

## Microphone fixes

- Dictation now works from the unsaved new-chat composer. Its temporary `new` identifier no longer fails the saved-chat existence check. Deleted/protected saved-chat checks and private/E2EE speech gates remain enforced.
- Android declares both `RECORD_AUDIO` and `MODIFY_AUDIO_SETTINGS`, as required by Capacitor's WebView audio permission callback. The latter was missing and caused Permission denied even after the user allowed recording.
- Permission failures now explain the app/browser permission and device microphone privacy switch.

## File explorer and generated images

- Bounded read retries handle chat row revisions changing during streaming. A continuously changing transcript no longer hides already saved workspace files and generated media.
- Image/media events refresh the open explorer without reloading the chat. Existing raw-base64 image blobs decode as binary images for previews/exports.
- `session_file` can read existing text resources by their listed paths and preview existing raster images for vision-capable models, including on mobile. Images pass through the bounded vision pipeline, with normalized working previews saved in the encrypted session workspace. Originals are retained; working previews stay out of the library unless explicitly delivered.
- Import copies actual image/media bytes into a working file. The text-only write action refuses fake image files made by writing base64 as text. Image status includes the saved session paths, allowing the agent to recover outputs without another paid generation.

## Agent interaction

- The new `ask_user` tool supports up to three questions, single or multiple choices, and a custom text response for every question. It waits for explicit submission and cancels on abort/privacy lock.
- After a failed Venice image/media job, another generation requires a dialog showing the failed model and error, with **Retry generation** or **Skip generation**. This applies before automatic/similar approval policies. A failed job can receive only one retry decision per user turn, preventing repeated approval loops; another retry can incur a new charge.

English and Italian interface strings are included. Existing approval dialogs remain separate from general questions.

## Validation

Actions run TypeScript, regression/UI tests, engine routing/cache checks, new-chat speech/privacy tests, conflicting-row explorer tests, local image-preview tests, agent-question/retry tests and mobile browser interactions.

The production Capacitor WebView recorded audio and stopped its microphone tracks on Android API 34 and 35 emulators after recording permission was granted. Hardware microphones and vendor-specific Android builds still require device verification. Builds use the existing private Android signing identity and the unsigned personal Windows installer.

P2P collaboration is being developed separately and is not included in this patch.
