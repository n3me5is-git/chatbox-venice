# Chatbox Venice 1.39.1

Preserve the thinking level selected in the app for custom subscription model IDs that the OpenAI SDK does not recognize by name. The provider now explicitly classifies configured reasoning requests before SDK conversion; no internal SDK flag is required from the user. Production SDK tests send the same reasoning options produced by the UI, including custom IDs, `xhigh` and `max`, in both streaming and complete replies.

Includes all [1.39.0 improvements](v1.39.0.md): external-browser subscription login, native app OAuth transport, current Codex models, custom text/image endpoints, native search, source links and context controls with native Auto and chat/dedicated-agent overrides. The configured/declared model ceiling remains authoritative. Real account access and physical Android sign-in still require account/device confirmation.
