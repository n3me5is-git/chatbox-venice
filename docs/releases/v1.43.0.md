# Chatbox Venice 1.43.0

- Choose **Settings → Data & Backup → Archive storage** to move between internal storage and a removable SD card on Android, or a selected folder on desktop.
- Conversations, attachments, generated media, portable knowledge documents and encrypted RAG indexes follow the selected location. Device keys and lightweight indexes stay in the app profile.
- Migration verifies the encrypted destination before switching and cleaning up the source. Large existing files are copied directly to the destination, one at a time.
- Reconnect the original storage or restore its folder permission if it becomes unavailable. The app never starts a replacement archive automatically.
- English and Italian settings. See [archive storage](https://github.com/n3me5is-git/chatbox-venice/blob/main/docs/archive-storage.md) for scope, backup and recovery details.
