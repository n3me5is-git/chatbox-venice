# Chatbox Venice 1.40.1

Chat model menu entries give the model name the full row width and wrap long names instead of truncating them. Provider, capability and privacy icons appear below the name, followed by Venice catalog prices on a separate full-width row when available. Favorites, model information, selection and locked-model behavior remain accessible. Keyboard activation of an information or favorite button does not select the model.

The sidebar groups image creation, the local media library, collaborative chats, dedicated agents, Venice Studio and copilots under **Tools**. Collapse the group to make more room for projects and conversations. Its state is saved on the device and shared between desktop and mobile layouts. Search and New Chat remain available outside the group. New controls include English and Italian labels, with English fallback for other languages.

Validation covers narrow and desktop model rows, complete names, icon/price separation, no horizontal overflow, and sidebar space recovery, persistence and reopening, alongside the existing regression suites.

Android Work chats now register the same shared session tools as desktop, including subscription image generation, Venice opt-in/restriction rules, questions/approvals, encrypted workspace previews, owner-only conversation references and multi-agent delegation. Fresh requests and resumed calls use one registration path. Mobile web search honors separate engine tools. Native image tools remain available when only text models are saved in provider settings, and CLI capabilities distinguish native image tools from CLI image commands.
